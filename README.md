## 🚀 使用方法

### 直接运行 EXE
1. 双击 `dist\超大文件断点续传搬运器.exe` 或 `C:\超大文件断点续传搬运器_v2.exe`
2. 点击【浏览文件】或【浏览目录】选择要传输的文件
3. 点击【浏览】选择目标目录
4. 点击【开始传输】

### Python 源代码运行
```bash
python file_transfer.py
```

## 🎯 核心实现原理

### 断点续传机制
1. **文件分块**: 将文件按 4MB 切分为多个块
2. **进度记录**: 每个块传输完成后立即记录到 JSON
3. **断点恢复**: 下次传输时跳过已完成的块，从断点继续
4. **文件标识**: 使用 `源路径+目标路径+文件大小+修改时间` 生成唯一 MD5 标识

### MD5 校验流程
```
传输全部块完成 → 计算源文件 MD5 → 计算目标文件 MD5 → 对比校验
```

### 多线程模型
```
主线程 (GUI)
    ↓
传输线程 (Worker)
    ├─ 线程池 (4线程)
    │   ├─ 块传输线程 1
    │   ├─ 块传输线程 2
    │   ├─ 块传输线程 3
    │   └─ 块传输线程 4
    └─ 进度更新回调
```

## ⚙️ 配置参数

在 `FileTransferConfig` 类中可调整：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `CHUNK_SIZE` | 4MB | 分块大小 |
| `MAX_THREADS` | 4 | 最大线程数 |
| `PROGRESS_FILE` | `.transfer_progress.json` | 进度文件名 |

## 💡 使用技巧

1. **大文件建议**: 超过 10GB 的文件建议网络稳定时传输，避免频繁断点
2. **线程数调整**: 固态硬盘可适当增加线程数（最多 8）
3. **网络不稳定**: 分块大小可调整为 1-2MB，降低单个块失败概率
4. **批量传输**: 选择整个目录，自动保持目录结构
